## Hvordan kjøre appen
### Emulering med Android Studio
1. Åpne prosjektet i Android Studio.
2. Konfigurer en emulator eller koble til en fysisk enhet.
3. Klikk på "Run" for å bygge og kjøre appen på emulatoren eller enheten.
