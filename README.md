# 🚀 LiftOff

![Kotlin](https://img.shields.io/badge/Kotlin-FF5722?style=for-the-badge&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-4285F4?style=for-the-badge&logo=android&logoColor=white)

**LiftOff** is an Android application that provides a complete overview of weather conditions at a user-specified location and time. The app helps users determine whether it is safe to conduct a rocket launch by combining real-time weather data with a modern, user-friendly interface.

---

## 🎓 About the Project

This project was developed as part of the **IN2000 course at the University of Oslo**. The goal was to create a weather application specifically tailored for rocket launches, showcasing skills in Android development, Kotlin, and modern UI/UX design.

---

## 🔹 Highlights

- Visualizes weather data relevant for rocket launches  
- Seamless navigation between search, results, map view, launch windows, and favorites  
- Save favorite locations and launch windows  
- Modern, responsive, and accessible interface  
- Perfect project to showcase Android development and modern Kotlin skills  

---

## 📱 How to Run the App

### Emulation with Android Studio
1. Open the project in Android Studio.  
2. Configure an emulator or connect a physical device (API level 26 or higher).  
3. Click "Run" to build and launch the app on the emulator or device.
