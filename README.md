Git commands:

* git clone [repository-url] # Kloner repositoriet ned på din lokale pc
* git add [filnavn] # "Stager" filen for å pushes, altså forteller git at det er denne filen man vil pushe
* git commit -m "Commitmessage" # Commiter endringene på din lokale repository, med en tilhørende commit-melding
* git push # Pusher til hovedrepository
* git branch [branchname] # Lager ny branch
* git checkout [branchname] # Går over til en annen branch
* git branch # Lister alle branchene, og hvilken du er på
