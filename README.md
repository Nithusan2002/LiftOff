# 🚀 LiftOff

![MVVM](https://img.shields.io/badge/Architecture-MVVM-blue?style=for-the-badge)

**LiftOff** is an Android application that helps users determine whether a rocket launch is safe by visualizing **weather conditions for a specific location and time**.  
The app combines real-time weather data with a **modern, intuitive interface** built using Jetpack Compose.

---

## 🎓 About the Project

LiftOff was developed as a **group project** as part of the  
**IN2000 – Software Engineering with Project Work** course at the **University of Oslo**.

The goal of the project was to design and implement a **domain-specific weather application** focused on rocket launches, while working collaboratively in a development team and applying best practices in:
- Android development with Kotlin  
- Modern UI development using Jetpack Compose  
- Clean architecture, state management, and teamwork  

---

## ✨ Key Features

- 🌦️ Visualizes weather data relevant for rocket launches  
- 🗺️ Interactive map view with location-based weather data  
- ⏱️ Launch windows based on time-specific conditions  
- ⭐ Save favorite locations and launch windows  
- 🧭 Seamless navigation between search, results, map, and favorites  
- ♿ Modern, responsive, and accessible UI  

---

## 🧠 What This Project Demonstrates

- Collaborative development in a **team-based software project**
- Clean application architecture using **MVVM**
- API integration and asynchronous data handling
- State management with ViewModel and Coroutines
- Persistence using local databases
- Navigation and UI composition with Jetpack Compose
- Focus on usability, clarity, and maintainability

## ▶️ How to Run the App

### Using Android Studio
1. Clone the repository  
2. Open the project in **Android Studio**  
3. Set up an emulator or connect a physical device (API level 26+)  
4. Click **Run** to build and launch the app
